# TRANSIT / IL — public passenger demo

Compiled static front-end preview, published on free GitHub Pages. The commercial
source code and infrastructure remain in a separate **private GitHub repository**.

**This preview is not an approved transport ticket/payment service.**
The interactive fallback route network and departure times are fictional samples.
The real scheduled GTFS backend must be connected separately; it is intentionally
not included in this public static preview. No payments or live location data.
