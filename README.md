# TRANSIT / IL — PUBLIC DEMO

This is a non-operational public preview of the passenger UI. Code development, ticketing and regulated integrations remain in the separate private source repository.

All routes in the embedded interactive fallback are synthetic test data. The official-schedule panel requires its own GTFS service and will show disconnected on this static Pages build. There are no live bus locations, real payment collections or valid tickets.

The public build is generated and committed manually without paid hosting platforms.
